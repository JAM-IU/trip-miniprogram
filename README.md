# 滇西北自驾行程小程序 · 保姆级部署教程

> 本小程序包含这些功能：
>
> - **行程组**：创建/加入行程组，凭 6 位邀请码邀请伙伴，不同行程组数据完全隔离
> - **行程**：点任意一条可以改时间/说明/费用说明，也能添加/删除；长按打卡，点 📍 一键导航，同组所有人看到的是同一份
> - **AI 行程导入**：粘贴攻略文字或上传攻略截图（最多 4 张），AI 自动整理成结构化行程，预览调整后可一键导入（点行程页右下角 ✨ 按钮）
> - **出发倒计时**：按行程组的出发日期自动计算，旅行中显示第几天
> - **天气卡**：按行程组城市自动刷新当日天气
> - **携带清单**：同组共享，点一下打勾
> - **照片墙**：底部 dock 栏右侧入口，占位页已上线（敬请期待），服务器备案完成后正式开放
>
> 全程零代码操作，跟着下面 8 步走即可。总耗时约 30-40 分钟（大部分是等注册审核激活）。

***

## 第 1 步：注册小程序账号（免费，约10分钟）

1. 电脑浏览器打开 <https://mp.weixin.qq.com>
2. 点右上角 **「立即注册」** → 选择 **「小程序」**
3. 填写邮箱（必须是**没绑定过**公众号/小程序的邮箱，QQ邮箱、163邮箱都可以）→ 去邮箱收验证码
4. 信息登记：主体类型选 **「个人」**，填写你的姓名、身份证号、手机号，用你的微信扫码验证
5. 注册完成后，登录小程序后台：
   **设置 → 基本设置 → 开发设置（或"开发管理-开发设置"）**
   找到 **AppID(小程序ID)**，复制记下来，后面要用

> 注册即时生效，不用等审核。

## 第 2 步：安装微信开发者工具（约5分钟）

1. 打开 <https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 下载 **Windows 64位 稳定版**，正常安装
3. 打开工具，用你的微信扫码登录

## 第 3 步：导入本项目（约2分钟）

1. 把 `trip-miniprogram` 文件夹解压到电脑上任意位置（比如桌面）
2. 开发者工具首页点 **「+ 导入」**
3. 目录选择 `trip-miniprogram` 文件夹
4. AppID 填第 1 步记下的那个（会自动替换掉占位的）
5. 点 **「导入」**

## 第 4 步：开通云开发（约5分钟，新用户首月免费）

1. 工具栏点 **「云开发」** 按钮（云朵图标）→ 开通
2. 创建环境：名称随意（如 `trip`）
3. 付费方式选 **基础套餐**：
   - 新用户有代金券，**首月实际支付 0 元**
   - 行程结束后不想续费，回来把环境销毁即可（见文末"费用提醒"）
4. 等待约 1 分钟，环境创建完成

> 如果你只创建了一个环境，代码里**什么都不用改**，会自动使用默认环境。

## 第 5 步：创建数据库集合（约3分钟，关键步骤！）

1. 打开云开发控制台（工具栏"云开发"按钮进入）→ 左侧 **「数据库」**
2. 点 **「+」创建集合**，依次创建 **3 个集合**（名字必须一模一样，全小写）：
   - `trips`（行程）
   - `checklist`（携带清单）
   - `groups`（行程组）
3. **每个集合**都要设置权限：点进集合 → 右上角 **「权限设置」** → 选 **「自定义安全规则」** → 删除原有内容，粘贴下面这段 → 确定：

```json
{
  "read": true,
  "write": true
}
```

> 这一步是让同组所有人都能读写数据。3 个集合都要设置，别漏！

## 第 5.5 步：部署天气云函数（约1分钟）

1. 开发者工具左侧目录树找到 `cloudfunctions/weather`
2. 右键 → **「上传并部署：云端安装依赖」**
3. 同样部署 `cloudfunctions/login`（静默识别用户用，不部署也不影响主功能）
4. 想用 **AI 行程导入**，再部署 `cloudfunctions/secCheck`（粘贴内容安全校验，不部署则 AI 导入不可用，其他功能不受影响）
5. 想用 **攻略截图识别**，还需一步：云开发控制台 → **AI+ → 模型管理** → 开通 **glm-5v-turbo**（视觉模型）

> 不部署 weather 也能用，天气卡会显示"天气参考"兜底数据。
> 纯文字导入用的是微信云开发内置的体验模型（免费），无需任何开通操作；群友微信版本太旧时会提示升级。
> 截图识别用的 glm-5v-turbo 是云开发售卖的模型，按 token 计费（新用户有免费算力额度，几个人偶尔导入几次几乎不花钱）；不开通也能用纯文字导入。

## 第 6 步：跑起来看看

1. 回到开发者工具，点顶部 **「编译」**
2. 首次打开会进入**行程组门页**：填名称创建一个行程组（会提示是否并入已有的滇西北示例数据）
3. 如果报错提示集合不存在 → 回到第 5 步检查集合名字

## 第 7 步：上传体验版，发到群里（约10分钟）

1. 开发者工具右上角点 **「上传」** → 版本号填 `1.0.0` → 确定，等待上传完成
2. 电脑浏览器打开 <https://mp.weixin.qq.com>，扫码登录小程序后台
3. 左侧 **「管理 → 版本管理」** → 找到 **开发版本** → 点 **「选为体验版」** → 会生成一个**体验版二维码**
4. 左侧 **「用户身份 → 成员管理 → 体验成员」** → 添加体验成员：
   - 输入群友的微信号，挨个添加（**个人小程序最多 15 人**，旅行团够用）
   - 微信会向对方发送邀请，对方同意后即可使用
5. 把体验版二维码发到微信群，大家扫码打开
6. 每个群友第一次打开：点**「加入朋友的行程组」**，输入你行程组卡片上的 6 位**邀请码**即可进组
7. 提醒群友：打开后点右上角 **「...」→「添加到我的小程序」**，以后从微信下拉就能找到

> 体验版不需要微信审核，上传即可用，长期有效。

## 第 8 步：怎么用（发群里给大家看的说明）

> **🧭 行程组**：第一次打开先加入或创建行程组。点底部 dock 栏中间的「行程组」随时可以切换/新建，点「复制」把邀请码发给朋友。
> **📱 行程**：点任意一条可以改时间/说明/费用说明；长按卡片打卡；有坐标的卡片点 📍 直接导航。谁改了同组的人都能看到。
> **✨ AI 导入**：点右下角 ✨ 按钮，粘贴攻略文字或点「＋攻略截图」传图（小红书攻略截图直接传，最多 4 张）→ 开始解析 → 预览里 ◀▶ 调天数、点标记换级别、删掉不要的 → 确认导入。AI 整理的结果记得核对一遍。
> **🎒 携带清单**：首页进度条点进去，点一下打勾，长按删除，底部可以自己加。
> **🌓 主题**：右下角小圆按钮在「跟随系统 → 白天 → 夜间」之间切换。
> **📷 照片墙**：点底部 dock 栏右侧「照片墙」进入，目前是占位页，正式上线后同组照片会汇总在这里。

## ⚠️ 保存失败 / 添加行程不生效？先看这里（99%是这个问题）

**典型表现**：行程列表显示正常（读取没问题），但点"保存"没反应或提示失败。

**原因**：云数据库集合默认是"仅创建者可读写"，写入被安全规则拦截（permission denied）。

**修复步骤（1分钟，不用改代码）**：

1. 微信开发者工具 → 工具栏 **「云开发」** → 进入云开发控制台
2. 左侧 **「数据库」** → 点进 **`trips`** 集合
3. 右上角 **「权限设置」**（有的版本叫「数据权限」或「安全规则」）
4. 切换到 **「自定义安全规则」**，删除原有内容，粘贴：

```json
{
  "read": true,
  "write": true
}
```

5. 点 **确定 / 保存 / 发布**（必须点，有的界面改完不会自动保存）
6. **`checklist` 和 `groups` 两个集合重复第 3-5 步**，三个都要设
7. 手机上把小程序从后台划掉，重新打开，再试保存

**验证权限是否生效**：重新打开集合的权限设置，看规则内容还在不在。不在就是没保存成功。

## 常见问题

| 问题                       | 解决办法                                                |
| ------------------------ | --------------------------------------------------- |
| 打开报错 env / invalid scope | 云开发环境没开好，重做第 4 步；若创建了多个环境，把 `app.js` 里的注释打开并填入环境ID  |
| 提示 collection not exists | 第 5 步的 3 个集合没建或名字不对（必须是 trips / checklist / groups） |
| 群友扫码打不开                  | 必须先在小程序后台把他加为"体验成员"并获对方同意                           |
| 加入时提示"没找到这个行程组"          | 邀请码输错了，让朋友重新复制发你（注意是 6 位大写字母数字）                    |
| 有人改了行程我看不到              | 下拉刷新一下，或重新进入小程序                                    |
| 保存失败 / 添加不生效             | 见上方「保存失败」专节，99% 是集合权限问题                              |
| AI 导入提示"缺少云函数 secCheck" | 部署 `cloudfunctions/secCheck`（右键 → 上传并部署：云端安装依赖）       |
| AI 导入提示"微信版本过低"        | 该成员微信太旧，升级微信到最新版即可                                   |
| AI 没解析出行程                 | 换一段更具体的攻略（包含每天去哪、时间），或直接手动添加                 |
| 截图识别提示"识图模型未开通"     | 云开发控制台 → AI+ → 模型管理 → 开通 glm-5v-turbo（纯文字导入不需要）   |
| 截图识别提示"图片上传失败"       | 云开发控制台 → 存储 → 权限设置，确认允许用户上传（默认即可）            |
| 想改小程序名字                  | 小程序后台 → 设置 → 基本设置 → 名称（可改）                          |

## 更新代码到体验版的方法

1. 用新的 `trip-miniprogram` 文件夹覆盖电脑上的旧文件夹（或删掉旧的重新解压）
2. 开发者工具里如果已打开该项目会自动刷新；否则重新导入
3. 点右上角 **「上传」**，版本号填 `1.0.1`
4. mp.weixin.qq.com → 版本管理 → 开发版本 → 如未自动更新，点最新版本的 **「选为体验版」**
5. 手机端：微信首页下拉 → 最近使用里长按该小程序 → 删除，再扫体验码进入（避免缓存旧版本）；或者等微信自动提示更新

## 项目结构（给想折腾的人）

```
trip-miniprogram
├── app.js / app.json / app.wxss     全局配置与样式
├── project.config.json              项目配置（AppID在这里填）
├── cloudfunctions/
│   ├── login/                       静默获取 openid
│   ├── weather/                     天气抓取（支持按行程组城市传参）
│   └── secCheck/                    文本内容安全校验（AI 导入前置检查）
├── utils/
│   ├── db.js                        云数据库分页拉取工具（支持 where 过滤）
│   ├── imgs.js                      景点/天数图片映射表
│   ├── ai.js                        AI 攻略解析（wx.cloud.extend.AI 调混元体验模型）
│   ├── scrollhide.js                滚动自动隐藏悬浮按钮
│   └── seed.js                      行程模板 + 日期/清单初始化工具
└── pages/
    ├── plan/                        行程页（查看/编辑/打卡/导航/天气/清单）
    ├── group/                       行程组门页（创建/加入/切换/数据迁移）
    ├── aiimport/                    AI 行程导入（粘贴攻略 → 预览调整 → 批量入库）
    └── photos/                      照片墙占位页（敬请期待）
```
